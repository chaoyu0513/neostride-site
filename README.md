# Neo Stride public site

Public product, support, and pre-release privacy pages for Neo Stride.

The site is deliberately static: it contains no analytics, cookies, trackers, or third-party embeds. GitHub Pages deploys the `main` branch through the workflow in `.github/workflows/pages.yml`.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.

## Before TestFlight external testing

- Replace the privacy draft with a reviewed policy and public contact details.
- Replace the beta placeholder with the approved TestFlight invitation path.
- Confirm the final URL in App Store Connect and the app's support contact.
