# Neo Stride public site

Public product, support, and reviewed privacy pages for Neo Stride.

The site is deliberately static: it contains no analytics, cookies, trackers, or third-party embeds. GitHub Pages deploys the `main` branch through the workflow in `.github/workflows/pages.yml`.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.
